K256 读取

监督运动 codec ID 为 1–256，末帧 STOP 为 0；标签数组 uint16。canonical tokenizer 字符串为 <k256_0>…<k256_256>，其中 codec ID 与目标模型 tokenizer ID 是不同命名空间，必须按字符串注册映射。K256 与RVQ-H5共用相同的真实宏节点；current/history均不补回跳过帧，下一目标原始帧号和真实时间戳由读取器给出。GT及全部256个运动码均须满足位移>10cm或转角>10°，包含末端最后一个运动动作；仅原始末帧输出STOP0。

Pointing + Object + RVQ-H5 读取

默认入口为 rvq/training_samples/index.json；通过 reader.samples 枚举索引指定的样本分片，不扫描全部原始帧。current/history 只含保留节点。五点局部绝对目标在当前观测坐标系内，forward/left/CCW；future_valid_mask 表示有效位姿。完整 [0,0,0] 与 <apos_1299> 仅终止帧共现；Object 不可见不会屏蔽 STOP。每次执行第一点后重新观测和更新历史。

样本字段与物理单位

分支核心字段形状与含义
K256action_token:uint16, frame_index, target_frame_index, target_timestamp_sec, recorded_action_dt_sec, is_stop离散宏动作；frame_index与target_frame_index为原始视频帧号；真实时间戳与间隔单位为秒且可变，仅作记录；0仅表示末帧 STOP
RVQ-H5tokens, rvq_codes:(3,), target_local:(5,3), future_valid_mask:(5,)Object/Pointing/3个码；五个 [forward,left,yaw] 绝对局部目标，平移 m、航向 rad；mask区分有效点与padding

请从 DATASETS.json 和 TRAINING_CONTRACT.json 确认最终绝对路径、split、监督数量、码本 SHA256 与 STOP 语义。只使用 DATASETS.json 中完成的 dataset/split 索引与 reader.samples，不扫描过滤清单或诊断目录。K256 码使用 uint16：1–256 表示运动，0 只表示末帧 STOP；当前图像、动作及历史均按保留宏节点的真实 frame index 对齐，不补回跳过帧。Pointing+Object+RVQ-H5 默认由 rvq/training_samples/index.json 指定样本并通过 reader.samples 读取；图像和 history 仅来自真实保留节点，读取原始 frame_index 与 timestamp，禁止按帧号补回跳过帧。五个未来位姿共享当前观测原点，坐标为前、左、逆时针；按 future_valid_mask 排除 padding。token 顺序、实际映射、STOP 双标记和逐点执行方式以 TRAINING_CONTRACT.json、token_ids.json 及 reader 为准。训练时使用提供的读取器；目标 tokenizer 必须实际注册 token 字符串，不能把 token_ids.json 的源码 ID 当模型 tokenizer ID。数据读取与离线量化验证不代表策略训练或真机效果。
